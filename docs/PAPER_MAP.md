# Paper-to-artifact map

Final proof: 3 main figures, 3 main tables, 3 Supplementary figures and 31 Supplementary tables. `paper_artifact_map.csv` maps all 40 items to their data and code. Table matrices retain exact displayed numbers and LaTeX cell notation; full-precision figure inputs and statistical CSVs supplement rounded table cells. They support checking published estimates. Recomputing an interval from individual predictions requires the corresponding frozen evaluation records and model artifacts.

Table captions, labels and final-proof page numbers are indexed in `table_index.json`. Pagination can change during production; item labels and captions are the stable references.
